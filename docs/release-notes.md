# v0.1.0-alpha.1 release notes

Status: prepared for the **Legacy/Git Public Alpha**, not published. This is a
source-only Linux x86_64 release profile built without embedding models. No public
download URL, release tag or reporting destination is established by these notes.

## Included

- Explicit local memories through MCP, with update/retirement, spaces, provenance,
  history and conflict inspection.
- Legacy Markdown/text ingestion and committed SHA-1 Git ingestion/re-ingestion.
- Lexical memory search/recall and Rust symbol search through CLI and stdio MCP.
- Private creation of admitted SQLite files/directories and confined MCP repository
  tools on hosts with effective Landlock ABI 3+.
- Source-install, client registration/undo and trusted-own-data offline recovery
  instructions. No account or model is needed for the standalone CLI/MCP examples.

Canonical document/PDF ingestion and M8 document publication are **not included**.
Private ownership/staging administration is unsupported. There is no automatic
conversation capture, native backup/restore command or aggregate storage quota.
Semantic/hybrid retrieval and real-model inference are outside this qualified
Alpha profile.

## Install and operate

Follow [the source-install guide](source-install.md): authenticate the publisher,
verify both GPG signatures and checksums using the packet's `VERIFY.txt`, then
extract and build. Rust/Cargo 1.98.1, Git, a C compiler and development headers are
required. The recommended noembed build needs no C++ runtime or weights; the
alternative default build also requires C++/libstdc++.

Before any ordinary command opens existing data with a new binary, preserve the
old binary and follow [offline recovery](offline-recovery.md). Schema changes can
occur on ordinary opens. Do not copy live MAIN alone or remove sidecars. The
recipe's process-visibility STOP is a safety prerequisite, not a corruption
finding; an unobservable potentially relevant process remains a STOP. Historical
qualified recovery results keep their exact environment/binary scope. A fresh
full backup/restore qualification was not obtained from the latest host guide run.

MCP is local unauthenticated stdio, spaces are not access controls, and storage is
not encrypted. See the [README limits](../README.md#known-limits),
[reference](reference.md) and [security policy](../SECURITY.md).
